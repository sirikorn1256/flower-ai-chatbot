## 🏗️ โครงสร้างสถาปัตยกรรมระบบ (System Architecture)

ระบบถูกออกแบบตามสถาปัตยกรรม **Static Site + Serverless Proxy** เพื่อความปลอดภัยระดับมาตรฐานอุตสาหกรรม:

```
[ผู้ใช้งานในเบราว์เซอร์]
        │
        ├─► GitHub Pages (index.html, chat-widget.js, config.js)
        │         │
        │         ├─► [ฐานข้อมูลความรู้] โฟลเดอร์ docs/ (6 ไฟล์ .txt)
        │         └─► [ดัชนีเวกเตอร์] vectors.json (Vector Embeddings)
        │
        ▼ (ผ่าน HTTPS อย่างปลอดภัย)
[Cloudflare Worker: worker.js] ◄─── เก็บ OPENROUTER_KEY ไว้ใน Secrets (ห้ามรั่วไหล)
        │
        ▼
[OpenRouter API]
   ├── Text Embedding: text-embedding-3-small (แปลงคำถามเป็นเวกเตอร์)
   └── LLM Generation: google/gemini-2.5-flash (เรียบเรียงคำตอบตามกติกา Grounding)
```

### ทำไมต้องมี Cloudflare Worker? (ตามคู่มือตอนที่ 2 หน้า 6)
1. **ซ่อน API Key ไม่ให้รั่วไหล:** ป้องกันผู้ใช้งานกด F12 Inspect บนหน้าเว็บ หรือเปิดดูโค้ดบน GitHub แล้วขโมย Key ไปใช้งาน
2. **ระบบควบคุมสิทธิ์ CORS (ALLOWED):** อนุญาตให้เฉพาะหน้าเว็บที่กำหนดเท่านั้นที่สามารถเรียก Worker ได้
3. **ลดภาระเบราว์เซอร์:** เป็นตัวกลางส่งต่อคำขอและแปลงผลลัพธ์ได้อย่างรวดเร็ว

## 🌟 ฟีเจอร์อัจฉริยะเด่นของระบบ (Key Features)

### 1. ระบบตอบคำถามจากเอกสารจริง (RAG Chatbot with Strict Grounding)
* ตอบจากเอกสาร 6 ไฟล์ รวม 38 ชิ้นส่วนอย่างแม่นยำ
* บังคับใช้ **"กติกาสามข้อ"** อย่างเข้มงวด:
  1. ตอบโดยใช้เฉพาะข้อมูลในเอกสารของร้านเท่านั้น
  2. หากไม่มีข้อมูล ให้ตอบปฏิเสธอย่างสุภาพและแนะนำเบอร์ติดต่อพนักงานจริง (`02-123-4567`)
  3. ห้ามเดา ห้ามแต่งเติมข้อมูลจากความรู้ทั่วไป
* แสดงแถบอ้างอิงแหล่งที่มา (`Citation`) ระบุชื่อไฟล์ ส่วนที่เท่าไร และคะแนนความสอดคล้อง (%) ใต้ทุกคำตอบ

### 2. เครื่องมือคำนวณงบประมาณอัตโนมัติ (Smart Budget Calculator)
* ผู้ใช้สามารถเลื่อนสไลเดอร์งบประมาณ (฿350 - ฿3,000+) เพื่อดูเซตช่อดอกไม้และวัสดุห่อช่อที่ตรงงบที่สุด
* สามารถกดปุ่มคลิกเดียวเพื่อส่งคำถามให้ AI ช่วยวิเคราะห์และแจกแจงค่าใช้จ่ายในแชทได้ทันที

### 3. จำลองช่อดอกไม้ & การ์ดอวยพรออนไลน์ (Bouquet & Digital Card Visualizer)
* เลือกผสมสายพันธุ์ดอกไม้ ปรับจำนวนดอก เลือกกระดาษห่อช่อ และลายริบบิ้น
* เขียนข้อความอวยพรส่วนตัว และแสดงผลพรีวิวแบบเรียลไทม์บน **HTML5 Canvas** พร้อมประเมินราคารวม
* สามารถกด **"📥 ดาวน์โหลดการ์ด & ภาพช่อนี้"** เป็นไฟล์ PNG นำไปส่งต่อให้คนพิเศษได้ทันที

### 4. ตัวจับคู่โอกาสพิเศษ (Occasion Matcher)
* แนะนำดอกไม้พร้อมความหมายมงคลสำหรับเทศกาลต่าง ๆ เช่น วันรับปริญญา (ทานตะวัน/ทิวลิป), วันวาเลนไทน์ (กุหลาบเอกวาดอร์), วันครบรอบ, เยี่ยมผู้ป่วย (มีระบบแจ้งเตือนห้ามใช้ดอกไม้เกสรฟุ้งหรือกลิ่นฉุนใน รพ.)

## 🚀 คู่มือการติดตั้งและทดสอบทีละขั้นตอน (Step-by-step Setup)

### ขั้นที่ 1: การเตรียม OpenRouter API Key
1. เข้าไปที่ [openrouter.ai](https://openrouter.ai) แล้ว Sign in ด้วย Google
2. ไปที่เมนู **Keys** กด **Create Key**
3. คัดลอกรหัสที่ขึ้นต้นด้วย `sk-or-v1-...` เก็บไว้ในที่ปลอดภัยบนเครื่องตัวเอง *(ห้ามใส่ใน config.js หรืออัปขึ้น GitHub เด็ดขาด)*

### ขั้นที่ 2: การสร้าง Cloudflare Worker
1. สมัครใช้งานและเข้าสู่ระบบ [dash.cloudflare.com](https://dash.cloudflare.com)
2. ไปที่เมนู **Workers and Pages** > กด **Create** > เลือก **Create Worker**
3. ตั้งชื่อ Worker เช่น `pim-flower-worker` แล้วกด **Deploy**
4. กด **Edit code** ลบโค้ดเดิมทั้งหมด แล้วนำโค้ดจากไฟล์ `worker.js` ไปวาง
5. แก้ไขตัวแปร `ALLOWED` ใน `worker.js` ให้มีโดเมน GitHub Pages ของตนเอง:
   ```javascript
   const ALLOWED = [
     "https://your-username.github.io",
     "http://localhost:8000"
   ];
   ```
6. กด **Deploy** มุมขวาบน
7. ไปที่แท็บ **Settings** > หัวข้อ **Variables and Secrets** > กด **Add**
   * **Name:** `OPENROUTER_KEY`
   * **Type:** เลือก **Secret** (ไม่ใช่ Text)
   * **Value:** ใส่ Key ที่ได้จาก OpenRouter
   * กด **Save and Deploy**
8. **ทดสอบ Worker:** เปิด URL ของ Worker ตรง ๆ ในเบราว์เซอร์ ควรได้ผลลัพธ์:
   ```json
   {"status":"ok","hasKey":true}
   ```

### ขั้นที่ 3: การตั้งค่า config.js
เปิดไฟล์ `config.js` แก้ไขค่าดังนี้:
```javascript
const CONFIG = {
  WORKER_URL: "https://pim-flower-worker.<your-account>.workers.dev", // ห้ามมี / ปิดท้าย
  SEARCH_MODE: "local", // ตั้งเป็น local ก่อนทดสอบ จากนั้นค่อยเปลี่ยนเป็น vector
  MODEL: "google/gemini-2.5-flash",
  DOCS_BASE: "docs",
  FILES: [
    "01-flowers-catalog.txt",
    "02-seasonal-flowers.txt",
    "03-wrapping-materials.txt",
    "04-occasions-meaning.txt",
    "05-bouquet-packages.txt",
    "06-shop-policy.txt"
  ],
  CHUNK_SIZE: 500,
  OVERLAP: 100,
  TOP_K: 3
};
```

### ขั้นที่ 4: การเปิดใช้งาน GitHub Pages
1. สร้าง GitHub Repository แบบ **Public**
2. อัปโหลดไฟล์ทั้งหมดขึ้น Repository
3. ไปที่แท็บ **Settings** > เมนู **Pages**
4. ในส่วน **Build and deployment** เลือก Branch เป็น `main` และโฟลเดอร์เป็น `/(root)` แล้วกด **Save**
5. รอ 1-3 นาที จะได้รับลิงก์เว็บไซต์พร้อมใช้งาน

### ขั้นที่ 5: การอัปเกรดเป็น Vector Search (ขั้นที่ 7 ในคู่มือ)
1. เปิดหน้า `https://<username>.github.io/<repo>/build-vectors.html` ในแท็บใหม่
2. วาง OpenRouter API Key ลงในช่อง แล้วกด **"เริ่มสร้างเวกเตอร์"**
3. ระบบจะแปลงเอกสารทั้ง 38 ชิ้นเป็นตัวเลขเวกเตอร์ 1,536 มิติ
4. กด **"ดาวน์โหลดไฟล์ vectors.json"** แล้วนำไฟล์มาอัปโหลดทับไฟล์เดิมบน GitHub
5. เปิดไฟล์ `config.js` แก้ไขบรรทัด:
   ```javascript
   SEARCH_MODE: "vector"
   ```
6. Commit changes แล้วเปิดหน้าเว็บใหม่ หัวกล่องแชทบอทจะเปลี่ยนสถานะเป็น **"ค้นแบบเวกเตอร์"**

## 🛠️ ตารางแก้ปัญหาที่พบบ่อย (Troubleshooting - อ้างอิงตอนที่ 7 ในคู่มือ)

| อาการที่พบ | สาเหตุ | วิธีแก้ไข |
|:---|:---|:---|
| **เปิดลิงก์แล้วขึ้น 404** | ชื่อไฟล์ไม่ใช่ `index.html` หรือ Repo เป็น Private | ตรวจสอบตัวสะกดชื่อไฟล์ และตั้งค่า Repo เป็น Public |
| **ไม่มีปุ่มวงกลมแชทขึ้นเลย** | ลืมเชื่อมต่อไฟล์สคริปต์ใน `index.html` | ตรวจสอบว่ามี `<script src="chat-widget.js"></script>` ก่อนแท็ก `</body>` |
| **Console ฟ้อง 403 Forbidden** | `ALLOWED` ใน `worker.js` ไม่ตรงกับโดเมนเว็บ | เพิ่มโดเมน GitHub Pages ลงในตัวแปร `ALLOWED` ใน `worker.js` แล้ว Deploy ใหม่ |
| **ตอบว่าระบบยังตั้งค่าไม่ครบ** | Cloudflare Worker ยังไม่ได้ใส่ Secret | เข้า Settings > Variables and Secrets ใส่ `OPENROUTER_KEY` ให้ถูกต้อง |
| **ขึ้นว่า Model not found** | ชื่อรุ่น AI ใน `config.js` ไม่ถูกต้อง | ตรวจสอบชื่อรุ่นล่าสุดจากหน้าโมเดลของ OpenRouter เช่น `google/gemini-2.5-flash` |
| **429 Rate Limit Exceeded** | โควตาของรุ่นทดสอบฟรีหมดชั่วคราว | รอสักครู่ หรือเปลี่ยนรุ่นโมเดลใน `config.js` |
| **แชทบอทตอบมั่วไม่ตรงเอกสาร** | เนื้อหาเอกสารไม่ครบ หรือยังไม่ได้อัปเดตเวกเตอร์ | ตรวจสอบเนื้อหาใน `docs/` และรัน `build-vectors.html` ใหม่ |
| **จู่ ๆ เปลี่ยนเป็นเทียบตัวอักษร** | ไฟล์ `vectors.json` ขัดข้องหรือดาวน์โหลดไม่ได้ | ระบบถอยไปใช้โหมด Local Search สำรองอัตโนมัติเพื่อให้เว็บยังคงใช้งานต่อได้ |

## ⚖️ จริยธรรมและข้อกำหนดด้านความปลอดภัย (Ethical AI)

1. **การแจ้งเตือนความโปร่งใส:** ภายในกล่องแชทมีแถบแจ้งเตือนชัดเจนว่าระบบทำงานด้วย AI และแสดงหมายเลขโทรศัพท์พนักงานจริง `02-123-4567`
2. **ความปลอดภัยของข้อมูล:** ไม่มีการเก็บประวัติการสนทนาส่วนบุคคล และไม่ขอข้อมูลบัตรเครดิตหรือข้อมูลอ่อนไหวผ่านแชท
3. **การปกป้อง API Key:** กุญแจถูกเก็บเป็นความลับบน Cloudflare Worker เสมอ
